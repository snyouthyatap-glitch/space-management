# 가상 시트 데모

이 데모는 서버 코드(`APPS_SCRIPT_READY.gs`)를 수정 없이 내 컴퓨터의 가상 구글 시트 위에서 실행해요. 직원 프로그램과 이용자 QR 화면을 실제처럼 써 볼 수 있어요.

- 실제 구글 시트와 네이버에는 아무것도 보내지 않아요.
- 이름과 연락처는 모두 가짜예요.

## 실행

1. 데모 서버를 켜요.

   ```bash
   npm run demo
   ```

   - 켤 때마다 가짜 데이터로 새로 시작해요.
   - 지난 데모를 이어서 쓰려면 `npm run demo:keep`을 실행해요.

2. 직원 프로그램을 데모 모드로 켜요.

   ```bash
   "staff-dashboard/publish-20261117b/청년이봄 직원알림.exe" --virtual-sheet=http://127.0.0.1:8787/exec
   ```

   - 데모 모드는 실제 설정과 따로 떨어진 데모 전용 폴더를 써요.
   - 원래 쓰던 직원 프로그램과 동시에 켤 수 있어요.
   - 네이버는 실제로 열지 않아요. 대신 `outputs/demo/naver-booking-sync.json`에 있는 가짜 결과를 읽어요.
   - 연결 설정은 바꿀 수 없게 잠겨 있어요.

3. 이용자 QR 화면은 `http://demo.localhost:8787/?entry=demo-entry`에서 열어요.
   - 전화번호 끝자리는 1111, 2222, 3333, 4444, 5555, 6666 중 하나를 넣어요.

4. 가상 시트 내용은 `http://127.0.0.1:8787/sheet`에서 볼 수 있어요. 10초마다 새로고침돼요.
